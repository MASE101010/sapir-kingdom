# הממלכה של משפחת ספיר

ממלכה תלת ממדית שנבנית מהעוקבים של @sapir.kingdom. כל עוקב מקבל בית, וכל יום התגובה עם הכי הרבה לייקים נבנית בקוד,
מצולמת בקוד ועולה כריל. Claude מריץ אותה כל יום (CLAUDE.md). הקמה חד פעמית: SETUP.md.

- `npm run check`: בדיקת הממלכה
- `node reel/render.mjs --day N --frames 1,10,20`: תמונות מתוך הריל של יום N (בלי קול)
- `node tools/dev-seed.mjs 3000` ואז `--dev`: לעבוד עם תושבי בדיקה
